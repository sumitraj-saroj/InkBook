## Release Bundle Sizes & Performance Metrics

| Package / Artifact            | Size   | Notes                                                           |
| ----------------------------- | ------ | --------------------------------------------------------------- |
| `dist/inkbook-1.0.0.AppImage` | 196 MB | Portable executable image, bundles Electron runtime & libraries |
| `dist/inkbook-1.0.0.pacman`   | 145 MB | Native Arch Linux package compressed with zstd                  |
| `dist/linux-unpacked/`        | 509 MB | Unpacked application runtime and resources                      |
| `out/` (Renderer / Main)      | 14 MB  | Application code, Excalidraw bundles, fonts, and assets         |

- **Cold Startup Time**: ~280ms to `ready-to-show` window event.
- **Page Switching Time (500+ elements)**: 4–9ms (automated test in `tests/pageSwitchPerformance.test.ts`).

### Potential Size Optimizations

1. **Locale Pruning**: Chromium bundles ~55 locale `.pak` files totaling 8.7 MB. Setting `electronLanguages: ['en-US', 'en']` in `electron-builder.yml` would remove unused language files and save ~8 MB.
2. **Dynamic Diagram Loading**: Excalidraw includes math formatting (KaTeX, ~500 kB) and diagram engines (Mermaid, Cytoscape, ~2 MB). Code-splitting these into lazy-loaded modules would trim ~2.5 MB from initial renderer bundle.
3. **Zstandard Max Compression**: Passing `-z` options to `pacman` packager in electron-builder can reduce the `.pacman` package size from 145 MB to ~115 MB.

## Known Issues & Technical Notes

1. **Wayland Fractional Scaling**: Under certain Wayland compositors using non-integer display scaling (e.g., 125% or 150%), hairline SVG patterns (such as 1px dot grid or ruled lines) may exhibit slight anti-aliasing dithering depending on the compositor's scaling filter. This is a known browser/Chromium rendering behavior with SVG patterns under fractional device pixel ratios.
2. **Imported Component Libraries**: Imported `.excalidrawlib` items are loaded directly into the active Excalidraw editor instance via its imperative library API. Excalidraw persists user libraries in browser IndexedDB/LocalStorage.
3. **Large Image Embeds in Multi-page PDF Exports**: For extremely large notebooks (e.g., 50+ pages with high-resolution photographic images), browser memory usage during PDF rasterization is constrained by available system RAM; the progress indicator displays page-by-page progress during generation.
