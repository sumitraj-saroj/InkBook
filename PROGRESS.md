## Known Issues & Technical Notes

1. **Wayland Fractional Scaling**: Under certain Wayland compositors using non-integer display scaling (e.g., 125% or 150%), hairline SVG patterns (such as 1px dot grid or ruled lines) may exhibit slight anti-aliasing dithering depending on the compositor's scaling filter. This is a known browser/Chromium rendering behavior with SVG patterns under fractional device pixel ratios.
2. **Imported Component Libraries**: Imported `.excalidrawlib` items are loaded directly into the active Excalidraw editor instance via its imperative library API. Excalidraw persists user libraries in browser IndexedDB/LocalStorage.
3. **Large Image Embeds in Multi-page PDF Exports**: For extremely large notebooks (e.g., 50+ pages with high-resolution photographic images), browser memory usage during PDF rasterization is constrained by available system RAM; the progress indicator displays page-by-page progress during generation.
